# Serena - Personal Portfolio Website

A modern, responsive personal portfolio website featuring a clean design, smooth animations, and an intuitive user experience.

## Features

- 🎨 **Modern Design** - Clean, professional interface with gradient accents
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Smooth Animations** - Engaging scroll animations and transitions
- 🎯 **Easy Navigation** - Sticky navigation bar with active section indicators
- 📝 **Contact Form** - Built-in contact form for easy communication
- 🚀 **Performance Optimized** - Fast loading and smooth scrolling

## Sections

1. **Hero** - Eye-catching introduction with call-to-action buttons
2. **About** - Personal information and skills showcase
3. **Portfolio** - Project gallery with descriptions
4. **Contact** - Contact form and social links
5. **Footer** - Copyright information

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox/Grid)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Getting Started

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser

No build process or dependencies required - just open and run!

### Customization

#### Update Content

Edit `index.html` to change:
- Your name and title
- About section text
- Portfolio projects
- Contact information
- Social media links

#### Change Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --text-dark: #1e293b;
    --text-light: #64748b;
    /* ... more variables */
}
```

#### Add Your Photos

Replace the placeholder elements with your actual images:
- About section image
- Portfolio project images
